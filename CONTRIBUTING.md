# Contributing to Ark of Art

Thank you for your interest in contributing to Ark of Art!

We welcome contributions from developers, designers, artists, organizers, and community members.

## Ways to Contribute

- Report bugs
- Suggest new features
- Improve documentation
- Enhance UI/UX
- Submit pull requests
- Help with translations
- Share ideas for improving the platform

## Code Style

Please keep code clean, documented, and easy to understand.

## Community

Be respectful and constructive when collaborating with others.

Thank you for helping build a global platform for artists!
